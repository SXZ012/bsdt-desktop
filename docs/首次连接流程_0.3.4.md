# 0.3.4 首次连接流程

未保存有效服务地址的客户端首次启动显示独立连接配置页：服务地址、测试连接、保存并进入。地址为空时不请求后台，不默认连接127.0.0.1，不进入空看板。

测试连接只校验输入地址，不保存。保存并进入会重新检查服务是否可访问及接口版本是否兼容，通过后保存规范化地址并进入市场看板。无效地址、无法连接、不兼容及存储失败有明确提示，失败不保存、不进入。界面不显示网卡、局域网候选地址或高级连接查询。

已配置客户端与升级客户端保留地址，以后启动自动连接并刷新。断线时保留工作台及已有缓存；可以在设置与连接中更换服务地址。后台的地址查询接口仍供部署工具使用，客户端不再调用。

TypeScript、6项前端单元测试、12类首次配置流程、5类启动回归及已安装桌面首次配置、保存后自动连接、设置页和单实例验证完成情况，以 outputs/verification/v034 下的结果记录为准。本机验证使用真实本地后台；另外两台电脑的公司局域网接入仍待实际联调。
