# 三台电脑局域网联调清单

实际跨电脑联调尚未完成。以下记录应由另一台电脑实际操作后填写结果，不能由本机测试替代。

1. 后台电脑运行0.2.0后台，保持开机且不休眠。运行ipconfig查询有效IPv4；先前为10.0.0.3，重新确认，不把这个地址当作永久固定值。
2. 两位同事各安装0.2.0桌面客户端，连接公司hualiwifi，在设置中填 http://后台IPv4:8765。后台电脑本机仍可填 http://127.0.0.1:8765。
3. 在同事电脑浏览器访问 /api/health，确认status=ok且api_version=2。记录电脑、实际IP、连接时间与结果。
4. 无法访问时先确认WiFi设备隔离、网络路由和后台电脑防火墙。由公司管理员只为可信私有网络放行TCP8765；不开放公网，也不清空防火墙规则。
5. 核对三台显示同一模块版本和数据日期，并确认报告和个股可以使用不同日期。
6. 用新的独立模拟批次测试自动刷新。待确认不替换旧版，确认完成后两位客户端应在下次刷新显示新版本。
7. 停止后台，两位客户端应保留自身已缓存数据与原日期并显示断线；重启后台，刷新应恢复。未访问过的详情/页在断线时不能伪造，应提示无缓存或读取失败。
8. 检查后台电脑重启后的人工启动、IPv4是否变化，以及客户端保存的地址是否需要更新。

本版不设置开机自启，不实现自动发现服务器，无登录，仅供可信内部网络。跨电脑联调结果继续在Excel中保持进行中/待配合。
