# 0.3.1 界面用语规范

设置页统一使用“服务连接”“服务地址”“局域网接入地址”“当前服务地址”“最近连接时间”。移除“同事连接地址”“复制后发给同事”“三台客户端”等面向特定人员的说明，连接错误与更新提示采用统一系统术语。研究数据的样例标识、日期及发布状态继续保留。

所有客户端由同一个安装包生成，使用同一套界面与接口。各客户端连接同一个数据服务后读取同一份已发布结果。服务地址、刷新周期、筛选条件等本地设置可以因设备不同而不同；断线设备显示缓存并提示连接状态。

本次修改仅涉及文案与版本号，未改变数据导入、确认发布、缓存或查询逻辑。验证结果见 outputs/verification/v031。另一台电脑的实际安装与公司局域网访问仍待配合验证。
