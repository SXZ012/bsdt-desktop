# 0.3.3 启动显示修复

原窗口创建后立即显示，而 HTML 根节点在前端脚本执行前没有内容，导致启动时出现深色空白。

窗口改为首帧绘制准备完成后显示。HTML 内置品牌图标、启动提示及进度动画，前端尚未准备完成时提供可见状态。界面显示不等待后台网络请求，后台离线时仍可进入工作台并显示连接状态及缓存。脚本加载失败或启动超时提供重新加载操作。

增加单实例限制。重复打开聚焦已有工作台；启动首帧尚未准备好时不提前显示窗口。

验证涵盖首帧显示时机、重复启动、模拟慢脚本、后台离线、脚本加载失败、本机安装及原生连接。证据集中在 outputs/verification/v033。记录的启动耗时仅代表本机测试，不能代表其他设备冷启动耗时。
