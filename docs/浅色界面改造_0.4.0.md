# 0.4.0 浅色研究界面

按确认方案统一采用雾灰背景、白色内容区、浅灰蓝导航、深蓝文字及蓝色主操作。青绿用于连接与确认状态，橙色用于待确认和样例提示，暗红用于风险及失败，紫色用于报告标识。文字状态继续保留，不仅依靠颜色区分。

首页将行业卡片改为最多六行的行业观察列表，名称、状态、研究依据可并排比较。四个模块的日期、版本和样例标识集中在数据概况栏，仍分别显示各自真实数据日期。保留市场来源详情及更新提示。

行业、个股采用白色表格、浅灰表头、行分隔和浅蓝选择状态。详情正文与报告正文调整为15px，报告目录选中使用浅紫色。设置页自然高度分组，连接信息集中到服务连接区域；发布规则以紧凑横栏展示。首次配置和启动提示同步采用浅色。

未修改研究结果、分析策略、导入、发布确认、存储和后台查询规则。六项前端单元测试、首次配置与五页交互、窄窗口及启动回归通过；本机安装验证结果见 outputs/verification/v040。浏览器工具内核仍不可用，视觉检查使用项目既有自动化截图流程，不声称内置浏览器验证。其他电脑的实际局域网连接仍待验证。
